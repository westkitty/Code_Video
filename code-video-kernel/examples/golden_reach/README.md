# Golden Scene v0.3.0 — The Reach

This original, noncanonical demonstration was rendered from the source in this plugin on a VTK/EGL host.
Four continuous volumetric limb meshes deform with normalized two-bone CPU linear-blend skin weights.
The actor uses mathematical two-link IK, feet fixed in world space, parented head/face rotation,
and world-to-right-hand orb ownership at 9.3 seconds.

12 seconds, 288 source frames, 24 FPS, 960x540, H.264/yuv420p, silent by design; no subtitles.
The sample MP4 is a **demonstration**, not evidence that this host has Blender or a connected ChatGPT MCP server.
The original signed shot receipts and frame sequences are runtime-specific: signatures rely on a local
workspace secret and are NOT portable proof across machines.

To regenerate on an authorized host, see root README commands for three source-verified shot batches.
The film.json performance tracks are editable, but the benchmark contact and timing invariants are locked.
