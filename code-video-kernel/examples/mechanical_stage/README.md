# Mechanical stage example

This MP4 is a real 6-second VTK-EGL-rendered demonstration of a segmented 3D puppet. Joint curve data is in `rig_scene.json`. It is noncanonical, intentionally silent, basic production-health footage, not a high-end film or an organic Blender sample.

A signed receipt is NOT bundled: local HMAC keys are not portable. Recreate your own proof by running `codevideo vtk-demo EXAMPLE_ID` in a fresh dedicated workspace. Never claim the bundled reference MP4 itself certifies a new deployment.
